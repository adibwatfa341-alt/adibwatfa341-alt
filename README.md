### About me

I build AI services that keep working in production, not only in a demo. My background is Python backend engineering, so I treat an AI feature as a complete product: async workers, validated outputs, retries, monitoring, tests and deployment.

### What I have built at Metamas

> The code for these projects belongs to Metamas and is private. The descriptions below are mine; the numbers come from the projects themselves.

| Project | What it does | Highlights |
|---|---|---|
| **Enterprise Document Intelligence** | Turns utility work-order PDFs (up to 94 pages) into structured, typed JSON with a Vision LLM | Grew the extraction catalog from **1 to 15 work-order types** and 60+ fields · OpenCV page routing with **zero LLM calls** · FastAPI + Celery + Redis + Flower |
| **Zero-Shot Industrial Anomaly Detection** | Finds defects in industrial parts without defect training examples (AnomalyCLIP + SAM 3) | Calibration raised recall from **15% to 80%** and cut false alarms from **27% to 0%** · 18 REST endpoints · deployed on **NVIDIA DGX Spark** · 74 tests |
| **Talent Assessment Platform** | Arabic (RTL) online assessment used to screen **200 university students** | Auto-scores **28 of 30** questions · server-signed timer and anti-cheating · Excel export · Docker + Nginx |
| **PDF-to-Markdown Service** | Converts PDF pages to clean Markdown with a multimodal LLM (Gemma), Arabic and English | Distributed **Redis rate limiter** (atomic Lua) shared by all Celery workers · exponential-backoff retries · 20 tests |
